# ขั้นตอนติดตั้งระบบบันทึกประวัติ (Google Apps Script)

ระบบหลังบ้านตามบทที่ 3.3.3 ใช้ Google Apps Script เป็นตัวรับข้อมูลและ Google Sheets เป็นฐานข้อมูล
เอกสารนี้เป็นขั้นตอนติดตั้งแบบทำตามได้ทีละข้อ พร้อมวิธีแก้เมื่อติดปัญหา

ใช้เวลาประมาณ 10 นาที ต้องมีบัญชี Google

## ก่อนเริ่ม ควรทราบ

- แผ่นงานที่สร้างจะเป็น**ทรัพยากรส่วนตัวของบัญชีคุณเท่านั้น** ผู้ใช้ทั่วไปเข้าถึงโดยตรงไม่ได้
  ตรงกับข้อจำกัดที่ระบุไว้ในบทที่ 3.3.3 ว่ารุ่นสาธิตยังไม่มีการแยกบัญชีผู้ใช้
- ระบบส่งเฉพาะค่าสรุปเชิงตัวเลขไปบันทึก **ไม่ส่งโค้ด HTML ต้นฉบับ** ที่นำมาตรวจ
  และฝั่งสคริปต์ปฏิเสธคำขอที่แนบโค้ดต้นฉบับมาด้วยอีกชั้นหนึ่ง

## ขั้นตอน

### 1. สร้างแผ่นงานและเปิดตัวแก้ไขสคริปต์

1. ไปที่ [sheets.new](https://sheets.new) เพื่อสร้าง Google Sheets เปล่า
2. ตั้งชื่อไฟล์ตามต้องการ เช่น `ประวัติการประเมิน WCAG`
3. เมนู **ส่วนขยาย** (Extensions) → **Apps Script**

### 2. วางโค้ด

1. ลบโค้ดตัวอย่างใน `Code.gs` ออกให้หมด
2. เปิดไฟล์ `apps-script/Code.gs` ของโครงงาน คัดลอก**ทั้งไฟล์** มาวางแทน
3. กด **บันทึก** (ไอคอนแผ่นดิสก์ หรือ Ctrl+S)

### 3. รันฟังก์ชันทดสอบก่อน — ขั้นตอนนี้ห้ามข้าม

ขั้นตอนนี้ทำสองอย่างพร้อมกัน คือ**ขออนุญาตให้สคริปต์เข้าถึงแผ่นงาน** และ**พิสูจน์ว่าเขียนข้อมูลได้จริง**
ก่อนจะไปยุ่งกับการ Deploy ทำให้เมื่อเกิดปัญหาภายหลังจะรู้ได้ทันทีว่าไม่ได้เกิดจากส่วนนี้

1. ที่แถบด้านบน เลือกฟังก์ชัน **`testAppendRow`** จากรายการดรอปดาวน์
2. กด **เรียกใช้** (Run)
3. จะมีหน้าต่างขออนุญาตขึ้นมา → **ตรวจสอบสิทธิ์** → เลือกบัญชีของคุณ
4. หากขึ้นคำเตือน "Google ยังไม่ได้ยืนยันแอปนี้" → กด **ขั้นสูง** (Advanced) → **ไปที่ ... (ไม่ปลอดภัย)**
   คำเตือนนี้เป็นเรื่องปกติของสคริปต์ที่เขียนเอง เพราะยังไม่ผ่านการตรวจสอบของ Google
5. กลับไปดูที่แผ่นงาน จะเห็นชีตชื่อ `assessment_history` ถูกสร้างขึ้นพร้อมหัวตารางและข้อมูลตัวอย่างหนึ่งแถว

**ถ้าถึงขั้นนี้แล้วเห็นข้อมูลในแผ่นงาน แปลว่าส่วนที่ยากที่สุดผ่านแล้ว**

ลบแถวตัวอย่างนั้นทิ้งได้เลย หรือจะเก็บไว้ก็ได้

### 4. Deploy เป็น Web app

1. มุมขวาบน กด **Deploy** → **New deployment**
2. กดไอคอนเฟือง ข้าง "Select type" → เลือก **Web app**
3. ตั้งค่าสองช่องนี้ให้ถูก **สำคัญที่สุด**

   | ช่อง | ต้องเลือก |
   | --- | --- |
   | Execute as | **Me** (บัญชีของคุณ) |
   | Who has access | **Anyone** |

   ⚠️ ต้องเป็น **Anyone** เท่านั้น ไม่ใช่ *Anyone with Google account*
   ถ้าเลือกผิด หน้าเว็บจะเรียกไม่ได้เพราะ Google จะบังคับให้ล็อกอินก่อน

4. กด **Deploy**
5. คัดลอกลิงก์ใต้หัวข้อ **Web app** ที่ลงท้ายด้วย `/exec`

### 5. เชื่อมกับหน้าเว็บและยืนยันผล

1. เปิดหน้าเครื่องมือ เลื่อนลงไปที่หัวข้อ **บันทึกประวัติและออกรายงาน**
2. วางลิงก์ที่คัดลอกมาในช่อง **ที่อยู่ Web App**
3. กด **ทดสอบการเชื่อมต่อ**

ควรได้ข้อความ *"เชื่อมต่อสำเร็จ ปลายทางพร้อมบันทึกข้อมูล"* พร้อมจำนวนรายการที่มีอยู่

4. ตรวจโค้ดสักชุดหนึ่ง แล้วกด **บันทึกผลการประเมิน**
5. ควรได้ข้อความ *"บันทึกลง Google Sheets เรียบร้อยแล้ว"* พร้อมหมายเลขแถว
6. กลับไปดูแผ่นงาน จะเห็นแถวใหม่เพิ่มขึ้น

ระบบจำลิงก์ไว้ในเบราว์เซอร์ของคุณเอง ครั้งต่อไปไม่ต้องกรอกใหม่

## เมื่อติดปัญหา

หน้าเว็บจะแปลสาเหตุให้อัตโนมัติ ตารางนี้สรุปว่าแต่ละข้อความหมายถึงอะไรและต้องแก้อย่างไร

| ข้อความที่เห็น | สาเหตุ | วิธีแก้ |
| --- | --- | --- |
| สคริปต์ยังต้องให้ผู้ใช้ลงชื่อเข้าใช้ Google ก่อน | ตั้ง Who has access ผิด | Deploy ใหม่ ตั้งเป็น **Anyone** |
| ปลายทางตอบว่าไม่พบฟังก์ชันที่เรียก | วางโค้ดไม่ครบ หรือลืมบันทึก | วางไฟล์ `Code.gs` ใหม่ทั้งไฟล์ แล้วกดบันทึก |
| ปลายทางตอบกลับเป็นหน้าเว็บแทน JSON | ลิงก์ผิด หรือยังไม่ได้ Deploy เป็น Web app | ตรวจว่าลิงก์ลงท้าย `/exec` และ Deploy เป็นชนิด Web app แล้ว |
| ที่อยู่ไม่ตรงรูปแบบของ Apps Script Web App | คัดลอกลิงก์ผิดตัว | ใช้ลิงก์ใต้หัวข้อ Web app ที่ลงท้าย `/exec` ไม่ใช่ลิงก์ `/dev` หรือลิงก์ของตัวแก้ไข |
| เชื่อมต่อไม่สำเร็จ (network error) | ลิงก์ผิด หรือเน็ตมีปัญหา | ลองเปิดลิงก์นั้นในแท็บใหม่ ควรเห็น JSON ขึ้นต้นด้วย `{"status":"ok"` |

**ตรวจเร็วที่สุด:** เอาลิงก์ `/exec` ไปเปิดในแท็บเบราว์เซอร์ตรง ๆ
ถ้าติดตั้งถูก จะเห็นข้อความประมาณนี้

```json
{"status":"ok","service":"WCAG preliminary assessment history","records":0}
```

ถ้าเห็นหน้าล็อกอินของ Google หรือหน้าแสดงข้อผิดพลาด แปลว่ายังตั้งค่าไม่ถูก

## เมื่อแก้โค้ดในสคริปต์ภายหลัง

Apps Script **ไม่ได้อัปเดตลิงก์เดิมอัตโนมัติ** ต้องกด Deploy ใหม่ทุกครั้ง

- ถ้าต้องการให้ลิงก์เดิมใช้ได้ต่อ: **Deploy → Manage deployments** → กดไอคอนดินสอ → Version เลือก **New version** → Deploy
- ถ้ากด New deployment จะได้ลิงก์ใหม่ ต้องนำไปเปลี่ยนในหน้าเว็บด้วย

## ข้อมูลที่ถูกบันทึกในแต่ละแถว

ตรงตามที่บทที่ 3.3.3 กำหนด

วันเวลาที่ประเมิน · เว็บไซต์ที่ตรวจ (หรือระบุว่าวางโค้ดเอง) · โหมดรับข้อมูล · คะแนน ·
จำนวนจุดที่ต้องแก้ · จำนวนจุดที่ต้องตรวจเพิ่ม · จำนวนองค์ประกอบทั้งหมด ·
จำนวนจุดที่ตรวจได้ จำนวนที่ไม่ผ่าน และอัตราไม่ผ่าน แยกตามหลักเกณฑ์ทั้งสามข้อ ·
คำตอบจากแบบประเมิน Checklist · เวลาที่ใช้วิเคราะห์และดึงข้อมูล · รุ่นของเครื่องมือ

**ไม่มีการบันทึกโค้ด HTML ต้นฉบับ** ในทุกกรณี

## สำหรับบทที่ 4

เมื่อติดตั้งเสร็จและทดสอบผ่านแล้ว ให้บันทึกหลักฐานเหล่านี้ไว้ประกอบการรายงาน

- ภาพหน้าจอข้อความ "เชื่อมต่อสำเร็จ" และ "บันทึกลง Google Sheets เรียบร้อยแล้ว"
- ภาพหน้าจอแผ่นงานที่มีข้อมูลจริงหลายแถว
- จำนวนครั้งที่ทดสอบบันทึก และมีครั้งใดล้มเหลวหรือไม่ เพราะเหตุใด
- เวลาที่ใช้ตั้งแต่กดบันทึกจนข้อมูลปรากฏในแผ่นงาน

ทั้งหมดนี้เป็นข้อมูลเชิงประจักษ์ที่ยืนยันเกณฑ์ **ความครบถ้วน** ในบทที่ 3.9
ซึ่งกำหนดว่าระบบต้องทำงานได้ครบตั้งแต่รับข้อมูลจนถึงส่งออกรายงาน
