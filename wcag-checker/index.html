  • มาตรฐานที่ตรวจหมายถึงอะไร
  • ข้อจำกัดของเครื่องมือ
  • ผลวัดความแม่นยำ

ตรวจการเข้าถึงเว็บไซต์ตาม WCAG 2.1

เครื่องมือประเมินและแนะนำการปรับปรุงเว็บไซต์เพื่อผู้พิการ แบบกึ่งอัตโนมัติ วางโค้ด HTML หรือระบุลิงก์ ระบบตรวจโครงสร้างให้ แล้วผู้ประเมินตอบอีกสามข้อที่โปรแกรมตัดสินแทนไม่ได้ ผลบอกว่าหน้าเว็บผิดที่ส่วนไหน ผิดมาตรฐานข้อใด และควรแก้อย่างไร

เริ่มตรวจโค้ด มาตรฐานที่ตรวจหมายถึงอะไร

  • มาตรฐานWCAG 2.1 ระดับ A และ AA
  • หลักเกณฑ์SC 1.1.1 · SC 1.3.1 · SC 1.4.3
  • วิธีตรวจอ่านโครงสร้าง HTML ร่วมกับแบบประเมิน 3 ข้อ
  • ผลลัพธ์คะแนน 0–100 พร้อมที่มาทุกขั้น

ข้อจำกัดที่ต้องทราบก่อนใช้งาน

  1. ระบบตรวจได้เฉพาะ กฎย่อยสี่กฎ ภายใต้หลักเกณฑ์สามข้อ ไม่ครอบคลุมทุกเทคนิคที่ WCAG กำหนด คะแนนเต็มจึงไม่ได้แปลว่าเว็บไซต์ผ่านหลักเกณฑ์เหล่านั้นอย่างสมบูรณ์
  2. ระบบวิเคราะห์เฉพาะโครงสร้าง HTML ที่รับเข้ามา ไม่ได้รันสคริปต์และไม่อ่านไฟล์ CSS ภายนอก เนื้อหาที่ JavaScript สร้างขึ้นภายหลังและสีที่กำหนดในไฟล์ CSS แยกจึงไม่ถูกตรวจ
  3. ผลการประเมินนี้ ไม่ใช่ใบรับรองความสอดคล้องกับมาตรฐาน WCAG 2.1 และไม่ทดแทนการตรวจสอบโดยผู้เชี่ยวชาญด้านการเข้าถึงเว็บไซต์

มาตรฐานที่เครื่องมือนี้ตรวจ หมายถึงอะไร

ทั้งสามหลักเกณฑ์อยู่ในหลักการที่ 1 การรับรู้ได้ (Perceivable) ของ WCAG 2.1 คือข้อมูลบนหน้าเว็บต้องนำเสนอในแบบที่ผู้ใช้ทุกคนรับรู้ได้ ระดับ A คือขั้นต่ำที่ต้องมี ส่วนระดับ AA คือระดับที่มาตรฐานส่วนใหญ่ใช้เป็นเป้าหมาย

นำเข้าโค้ดที่ต้องการตรวจ

เลือกวิธีนำเข้าหนึ่งวิธี ทั้งสองวิธีใช้ตรรกะการวิเคราะห์ชุดเดียวกันหลังจากได้ HTML แล้ว

วิธีนำเข้าข้อมูล
ลองด้วยตัวอย่าง:
วางทั้งหน้าหรือเฉพาะบางส่วนก็ได้ หากต้องการตรวจเนื้อหาที่ JavaScript สร้างขึ้น ให้คัดลอกโค้ดจาก Inspect Element หลังหน้าเว็บทำงานเสร็จแล้วมาวางแทน
ระบบดึง HTML ต้นฉบับผ่านบริการตัวกลาง จึงตรวจได้เฉพาะเนื้อหาที่เซิร์ฟเวอร์ส่งมาก่อนที่เบราว์เซอร์จะประมวลผล หากดึงไม่สำเร็จ ให้เปลี่ยนไปใช้วิธีวางโค้ดเอง ระบบปฏิเสธลิงก์ที่ชี้ไปยังเครื่องตนเองและเครือข่ายภายในองค์กร เพื่อป้องกันการใช้เครื่องมือเป็นช่องทางเข้าถึงระบบภายใน
หรือกด Ctrl + Enter ในช่องโค้ด

แบบประเมินสำหรับผู้ประเมิน (Checklist)

สามข้อนี้เป็นส่วนที่โปรแกรมตัดสินแทนไม่ได้ จึงต้องอาศัยดุลยพินิจของผู้ประเมิน หากยังไม่แน่ใจให้เลือก “ยังไม่ได้ตรวจ” ระบบจะตัดข้อนั้นออกจากการคำนวณคะแนน ไม่นับเป็นทั้งผ่านและไม่ผ่าน คำตอบที่เปลี่ยนจะคำนวณผลใหม่ทันที

บันทึกประวัติและออกรายงาน

ระบบส่งเฉพาะค่าสรุปเชิงตัวเลขไปบันทึกใน Google Sheets ผ่าน Google Apps Script ไม่ส่งและไม่จัดเก็บโค้ด HTML ต้นฉบับ ที่นำมาตรวจ

วางลิงก์ที่ได้จากการ Deploy สคริปต์ในโฟลเดอร์ apps-script ระบบจำค่านี้ไว้ในเบราว์เซอร์ของคุณเท่านั้น กด “ทดสอบการเชื่อมต่อ” ก่อนบันทึกครั้งแรก เพื่อยืนยันว่าติดตั้งสคริปต์สำเร็จ ขั้นตอนติดตั้งโดยละเอียดพร้อมตารางแก้ปัญหาอยู่ในไฟล์ docs/apps-script-setup.md ของโครงงาน
