ข้ามไปยังเนื้อหาหลัก

เครื่องมือประเมินและแนะนำการปรับปรุงเว็บไซต์เพื่อผู้พิการตามมาตรฐาน WCAG เบื้องต้น

การประเมินแบบกึ่งอัตโนมัติ ครอบคลุมกฎย่อยของ SC 1.1.1, SC 1.3.1 และ SC 1.4.3 ตาม WCAG 2.1 ระดับ A และ AA

ข้อจำกัดที่ต้องทราบก่อนใช้งาน

  • ระบบตรวจได้เฉพาะ กฎย่อยสี่กฎ ภายใต้หลักเกณฑ์สามข้อ ไม่ครอบคลุมทุกเทคนิคที่ WCAG กำหนด คะแนนเต็มจึงไม่ได้แปลว่าเว็บไซต์ผ่านหลักเกณฑ์เหล่านั้นอย่างสมบูรณ์
  • ระบบวิเคราะห์เฉพาะโครงสร้าง HTML ที่รับเข้ามา ไม่ได้รันสคริปต์และไม่อ่านไฟล์ CSS ภายนอก เนื้อหาที่ JavaScript สร้างขึ้นภายหลังและสีที่กำหนดในไฟล์ CSS แยกจึงไม่ถูกตรวจ
  • ผลการประเมินนี้ ไม่ใช่ใบรับรองความสอดคล้องกับมาตรฐาน WCAG 2.1 และไม่ทดแทนการตรวจสอบโดยผู้เชี่ยวชาญด้านการเข้าถึงเว็บไซต์

1นำเข้าโค้ดที่ต้องการตรวจ

เลือกวิธีนำเข้าข้อมูลหนึ่งวิธี ทั้งสองโหมดใช้ตรรกะการวิเคราะห์ชุดเดียวกันหลังจากได้ HTML แล้ว

โหมดรับข้อมูล
วางทั้งหน้าหรือเฉพาะบางส่วนก็ได้ หากต้องการตรวจเนื้อหาที่ JavaScript สร้างขึ้น ให้คัดลอกโค้ดจาก Inspect Element หลังหน้าเว็บทำงานเสร็จแล้วมาวางแทน
ระบบดึง HTML ต้นฉบับผ่านบริการตัวกลาง จึงตรวจได้เฉพาะเนื้อหาที่เซิร์ฟเวอร์ส่งมาก่อนที่เบราว์เซอร์จะประมวลผล หากดึงไม่สำเร็จ ให้เปลี่ยนไปใช้โหมดวางโค้ดเอง

ระบบปฏิเสธลิงก์ที่ชี้ไปยังเครื่องตนเองและเครือข่ายภายในองค์กร เพื่อป้องกันการใช้เครื่องมือเป็นช่องทางเข้าถึงระบบภายใน

2แบบประเมินสำหรับผู้ประเมิน (Checklist)

สามข้อนี้เป็นส่วนที่โปรแกรมตัดสินแทนไม่ได้ จึงต้องอาศัยดุลยพินิจของผู้ประเมิน หากยังไม่แน่ใจให้เลือก “ยังไม่ได้ตรวจ” ระบบจะตัดข้อนั้นออกจากการคำนวณคะแนน ไม่นับเป็นทั้งผ่านและไม่ผ่าน

4บันทึกประวัติและออกรายงาน

ระบบส่งเฉพาะค่าสรุปเชิงตัวเลขไปบันทึกใน Google Sheets ผ่าน Google Apps Script ไม่ส่งและไม่จัดเก็บโค้ด HTML ต้นฉบับ ที่นำมาตรวจ

วางลิงก์ที่ได้จากการ Deploy สคริปต์ในโฟลเดอร์ apps-script ระบบจำค่านี้ไว้ในเบราว์เซอร์ของคุณเท่านั้น หากเว้นว่างไว้ ปุ่มบันทึกจะถูกปิดการใช้งาน
