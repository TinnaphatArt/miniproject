  • ผู้พิการทางการเห็น ใช้โปรแกรมอ่านหน้าจอฟังข้อความแทนภาพ SC 1.1.1 ข้อความแทนภาพ
  • ผู้ใช้คีย์บอร์ดและโปรแกรมอ่านหน้าจอ นำทางตามหัวข้อ รู้ว่าแต่ละช่องให้กรอกอะไร SC 1.3.1 โครงสร้างและป้ายกำกับ
  • ผู้สูงอายุและผู้มีสายตาเลือนราง อ่านข้อความที่สีคมชัดได้ง่ายกว่า ทุกคนที่ใช้มือถือกลางแดดก็ได้ประโยชน์เช่นกัน SC 1.4.3 ความคมชัดของสี

WCAG คืออะไร

Web Content Accessibility Guidelines แนวทางของ W3C ที่บอกว่าเว็บไซต์ต้องทำอย่างไรให้ทุกคนเข้าถึงได้ รวมถึงผู้พิการ เครื่องมือนี้อ้างอิง WCAG 2.1 ระดับ A และ AA

เครื่องมือนี้ตรวจอะไรได้บ้าง

ตรวจ 3 หลักเกณฑ์ คือ SC 1.1.1 ข้อความแทนภาพ, SC 1.3.1 โครงสร้างหัวข้อและป้ายกำกับ และ SC 1.4.3 ความคมชัดของสี ด้วยกฎตรวจ 5 รหัส ร่วมกับแบบประเมิน 3 ข้อ

คะแนน 100 แปลว่าผ่าน WCAG หรือไม่

ไม่ คะแนนสะท้อนเฉพาะกฎที่ระบบตรวจได้ ไม่ใช่ใบรับรองความสอดคล้อง และไม่ทดแทนการตรวจโดยผู้เชี่ยวชาญ

โค้ดที่นำมาตรวจถูกเก็บไว้หรือไม่

ไม่ การวิเคราะห์ทำในเบราว์เซอร์ของคุณ ถ้าเลือกบันทึกผล ระบบส่งเฉพาะค่าสรุปเชิงตัวเลขไป Google Sheets ไม่ส่งโค้ด HTML

ทำไมบางเว็บตรวจสีไม่ได้

ระบบอ่านสีจาก style ที่เขียนไว้ในองค์ประกอบเท่านั้น ไม่อ่านไฟล์ CSS แยก ถ้าเว็บกำหนดสีใน CSS ระบบจะบอกว่าตรวจไม่ได้ แทนที่จะให้ผ่าน

มาตรฐานที่เครื่องมือนี้ตรวจ หมายถึงอะไร

ทั้งสามหลักเกณฑ์อยู่ในหลักการที่ 1 การรับรู้ได้ (Perceivable) ของ WCAG 2.1 คือข้อมูลบนหน้าเว็บต้องนำเสนอในแบบที่ผู้ใช้ทุกคนรับรู้ได้ ระดับ A คือขั้นต่ำที่ต้องมี ส่วนระดับ AA คือระดับที่มาตรฐานส่วนใหญ่ใช้เป็นเป้าหมาย

หลักการ 4 ข้อของ WCAG และส่วนที่เครื่องมือนี้ตรวจ

1. Perceivable รับรู้ได้

ข้อมูลต้องนำเสนอในแบบที่ทุกคนรับรู้ได้ เช่น ข้อความแทนภาพ สีที่คมชัด

เครื่องมือนี้ตรวจ 3 หลักเกณฑ์

2. Operable ใช้งานได้

ใช้งานได้ด้วยคีย์บอร์ด มีเส้นโฟกัส มีเวลาพอ

ยังไม่ได้ตรวจ

3. Understandable เข้าใจได้

ภาษาและฟอร์มชัดเจน แจ้งข้อผิดพลาดให้เข้าใจ

ยังไม่ได้ตรวจ

4. Robust รองรับได้

โค้ดถูกต้องตามมาตรฐาน ทำงานกับเทคโนโลยีช่วยเหลือได้

ยังไม่ได้ตรวจ

ระบบส่งเฉพาะค่าสรุปเชิงตัวเลขไปบันทึกใน Google Sheets ผ่าน Google Apps Script ไม่ส่งและไม่จัดเก็บโค้ด HTML ต้นฉบับ ที่นำมาตรวจ

วางลิงก์ที่ได้จากการ Deploy สคริปต์ในโฟลเดอร์ apps-script ระบบจำค่านี้ไว้ในเบราว์เซอร์ของคุณเท่านั้น กด “ทดสอบการเชื่อมต่อ” ก่อนบันทึกครั้งแรก เพื่อยืนยันว่าติดตั้งสคริปต์สำเร็จ ขั้นตอนติดตั้งโดยละเอียดพร้อมตารางแก้ปัญหาอยู่ในไฟล์ docs/apps-script-setup.md ของโครงงาน
ข้อมูลที่จะถูกส่งไปบันทึก
